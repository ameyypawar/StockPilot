# Presentation

`InventoryManagementSystem.pptx` is the 16:9, 12-slide project presentation
for **StockPilot — Inventory Management System** (title & team, problem &
objectives, architecture, tech stack, console app & OOP concepts, database
design, web modules, Stock In/Out flow, reports & printing, PWA features,
testing summary, conclusion & future scope), including speaker notes on
every slide. It is generated, not hand-edited — regenerate it after any
change to the code, the seed data, `tools/doc_config.py` or
`tools/test_results.json` with:

```
tools/.venv/bin/python tools/build_docs.py
```
